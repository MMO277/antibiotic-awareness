Update 13 - Complete All 16 Antibiotics Database, Prominent QR Codes & Box Barcodes
===================================================================================

ما الذي يقدمه هذا التحديث الشامل؟
---------------------------------
1. اكتمال جميع الأدوية الـ 16 بدون استثناء في الموقع:
   - أموكسيسيلين + كلافولانات (Augmentin / Curam / Megamox / Hibiotic)
   - أموكسيسيلين منفرد (E-Mox / Biomox / Amoxil)
   - بنسلين V البوتاسيوم (Ospen 1000 / Ospen 1500 / Calciopen)
   - أزيثرومايسين (Zithromax / Xithrone / Zithrokan)
   - ميترونيدازول (Flagyl / Amrizole / Dumozol)
   - نيتروفورانتوين (Macrofuran / Uvamin Retard)
   - سيبروفلوكساسين (Ciprofar / Cipromay / Ciprobay)
   - كليندامايسين (Dalacin C / Clindam)
   - كلاريثرومايسين (Klacid / Clarikan)
   - دوكسيسيكلين (Tabocin / Vibramycin / Doxymycin)
   - كوتريموكسازول (Septazole Forte / Sutrim Forte)
   - سيفوروكسيم (Zinnat / Cefurox)
   - سيفترياكسون (Epicephin / Cefaxone / Rocephin)
   - ليفوفلوكساسين (Tavanic / Levodel / Unilevo)
   - سيفالكسين (Ospexin / Cefalex / Ibilex)
   - سيفيكسيم (Suprax / Magnacef / Cefix)

2. لكل دواء من الـ 16 دواء الآن:
   - السعر الرسمي المحدث في السوق المصري (EGP) للأقراص والشراب والحقن.
   - قسم البدائل والمثائل المتطابقة والبدائل العلاجية عند نقص الدواء.
   - الباركود الدولي المعتمد لعلب الأدوية المصرية (EAN-13 يبدأ بـ 622) موثق.
   - رمز الـ QR Code الخاص بالعلبة ظاهر في بطاقة واضحة في أول وأعلى صفحة الدواء ليراه مستخدمو الموبايل فوراً.

الملفات المضمنة في هذا التحديث (5 ملفات):
----------------------------------------
1. seedData.ts       -> قاعدة البيانات الحصرية المكتملة لجميع الأدوية الـ 16
2. MedicinePage.tsx  -> رفع بطاقة كود QR والباركود لأعلى الصفحة + كروت السعر والبدائل
3. types.ts          -> تعريف كافة الحقول (السعر، البدائل، آلية العمل)
4. medicinesApi.ts   -> ربط ومطابقة باركود العلب مع الكاميرا والبحث التلقائي
5. styles.css        -> تنسيقات بطاقة الـ QR العلوية وكروت الأسعار
6. README-update13.txt -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات الخمسة إلى مستودع GitHub في نفس مسار App.tsx (استبدل الملفات القديمة).
2. اضغط Commit changes وانتظر دقيقة حتى تظهر علامة الصح الخضراء في Actions.
3. افتح صفحة الأدوية أو أي دواء في الموقع (مثل أموكسيسيلين أو أوسبن) وستجد كود الـ QR والسعر والبدائل والباركود ظاهرة ومكتملة!
