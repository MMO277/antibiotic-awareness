1. OVERVIEW OF COMPLETED IMPLEMENTATIONS & USER REQUESTS
---------------------------------------------------------
All 4 requested clinical & educational features + the grouped navigation architecture
have been fully unified, styled, and verified:

A) حاسبة «البديل الأرخص بنفس الكفاءة» (Generic Cost Saver - /cost-saver):
   - تسمح للمريض أو الصيدلي بإدخال اسم أي دواء موصوف (مثل Augmentin, Zithromax, Rocephin).
   - تعرض فوراً جميع المثائل المصرية المتطابقة 100% في المادة الفعالة، التركيز، والشكل الصيدلاني المرخصة من هيئة الدواء المصرية (EDA).
   - تقارن الأسعار الرسمية بدقة، وتحسب قيمة التوفير المالي بالجنيه المصري (EGP) والنسبة المئوية، مع تحديد البديل الأوفر لحل أزمة النواقص وغلاء الأسعار.

B) قسم التوعية ضد «حقنة البرد / الخلطة السحرية 3×1» (Cold Shot Mythbuster - /cold-shot-warning):
   - صفحة تفاعلية متكاملة تكشف خطورة خلط المضاد الحيوي الوريدي (مثل Ceftriaxone) مع كورتيزون (Dexamethasone) ومسكن (Ketolac/Voltaren) في سرنجة واحدة لنزلات البرد الفيروسية.
   - محاكاة بصرية لتفاعل السرنجة، وتوضيح أسباب الصدمات التحسسية القاتلة (Anaphylaxis)، وتوقف عضلة القلب، والفشل الكلوي الحاد، وتدمير المناعة.

C) مولّد جدول الجرعات للطباعة وواتساب (Printable Daily Schedule - /daily-schedule):
   - يحدد فيه المريض وقت استيقاظه وأدويته وعدد الجرعات (كل 6 / 8 / 12 / 24 ساعة).
   - يحسب المواعيد المتباعدة بدقة بالساعة صباحاً ومساءً مع تعليمات الأكل (قبل/بعد/مع الأكل).
   - يدعم تصدير الجدول فوراً كصورة ملونة عالية الدقة (PNG Poster) أو إرساله بنقرة واحدة عبر WhatsApp أو طباعته (Print) بتنسيق مخصص يتجاهل أزرار التحرير.

D) زر التبديل بين وضع المريض والوضع الإكلينيكي للطبيب (Clinical Pro Mode Toggle):
   - متاح في صفحات الأدوية (/medicine/:id) عبر زر تبديل تفاعلي (Patient Mode vs Doctor Pro Mode).
   - يعرض للطبيب بيانات تخصصية متقدمة: حركية الدواء PK/PD (فترة نصف العمر، الإتاحة الحيوية، الارتباط بالبروتين)، طيف البكتيريا المغطاة (Gram+, Gram-, Anaerobes, Atypicals)، وجدول تعديل الجرعات حسب تصفية الكرياتينين (CrCl)، وإرشادات الحقن الوريدي والتخفيف.
   - يعرض للمريض ملخصاً مبسطاً وسهلاً لتعليمات الجرعات والتحذيرات.

E) القائمة المجمّعة الذكية (Grouped Dropdown Navigation Menu):
   - تم القضاء تماماً على القائمة الطويلة الممتدة، وتجميع الأدوات والصفحات في 5 تصنيفات رئيسية ذكية:
     1. 💊 الدليل والبحث الدوائي (السجل 206، الباركود، المقارنة، والبديل الأرخص).
     2. 🏥 الفحص والأمان السريري (الحساسية، التداخلات، رادار الروشتة، الأطفال، حقنة البرد 3×1، والأعراض الجانبية).
     3. 🌿 متابعة العلاج والروشتة الخضراء (الروشتة الخضراء، مولّد الجرعات، المتابع، ملف صحتي، والتخلص الآمن).
     4. 🎮 الألعاب والمحاكاة والذكاء الاصطناعي (مركز الألعاب 3D، المساعد الذكي، الاختبارات، واستمع وتعلّم).
     5. 📚 التوعية والأبحاث والمصادر (حملة نوفمبر العالمية، الدليل، خرافة وحقيقة، المقالات، واستبيان البحث).
   - الشريط العلوي (Quick Ribbon) يحتوي على أزرار لكل تصنيف مع عداد، وبالضغط ينسدل Dropdown تفاعلي.
   - القائمة الجانبية (Drawer ☰) تدعم الـ Accordions القابلة للفتح والطي مع زر "فتح الكل / طي الكل".
