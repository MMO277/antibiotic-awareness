Update 15 - Clinical Drug & Food Interaction Checker (فاحص التفاعلات الدوائية والغذائية التمريضي)
========================================================================================

ما الذي يقدمه هذا التحديث النوعي لمشروع التخرج؟
---------------------------------------------
1. صفحة وأداة سريرية تفاعلية جديدة كلياً: "فاحص التفاعلات" (/interactions).
2. فحص فوري للتداخلات الدوائية والغذائية بين المضادات الحيوية وأشهر المواد:
   - أطعمة ومشروبات: الحليب ومنتجات الألبان، الكحول، الوجبات الدهنية.
   - مكملات غذائية: كبسولات الحديد، الكالسيوم، المغنيسيوم، البروبيوتيك والزبادي.
   - أدوية شائعة: حبوب منع الحمل، أدوية الكوليسترول (الستاتينات)، مميعات الدم (الوارفارين)، المسكنات (NSAIDs)، أدوية الحموضة.
3. مؤشر خطورة سريري ملون وواضح:
   - 🔴 تعارض خطير / ممنوع معاً (Severe): تحذير أحمر مع الشرح وآلية الخطر.
   - 🟡 تفاعل متوسط (Moderate): يحدد بالساعات كم ساعة يجب الفصل بين الدواء والطعام.
   - 🟢 آمن وموصى به (Safe): توضيح كيفية تناوله مع الطعام لتقليل اضطراب المعدة.
4. ركن خاص بكل تفاعل: "توجيه وتمريض سريري (Nursing Stewardship Note)" يبرز دور التمريض السريري في تقييم المريض وتثقيفه والإعطاء الآمن للأدوية.
5. أزرار فحص سريع (Quick Checks) لأشهر التفاعلات المتداولة بضغطة زر واحدة.

الملفات المضمنة في هذا التحديث (6 ملفات):
----------------------------------------
1. interactionsData.ts -> قاعدة بيانات التفاعلات السريرية والآليات الحيوية وتوجيهات التمريض
2. Interactions.tsx     -> صفحة فاحص التفاعلات التفاعلية
3. App.tsx             -> إضافة مسار الصفحة الجديدة (/interactions)
4. Layout.tsx          -> إضافة زر "فاحص التفاعلات ⚡" في شريط الموقع العلوي
5. i18n.tsx            -> الترجمة والتسمية
6. styles.css          -> التنسيقات البصرية للألوان والكروت وبطاقة التمريض
7. README-update15.txt -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات الستة إلى مستودع GitHub في نفس مسار App.tsx (استبدل الملفات القديمة).
2. اضغط Commit changes وانتظر دقيقة حتى تظهر علامة الصح الخضراء في Actions.
3. افتح موقعك وستجد زر "فاحص التفاعلات ⚡" متاحاً في الشريط العلوي وجاهزاً للعرض والمناقشة!
