تعديلات العالم المفتوح وتجربة المحاكاة

الملفات داخل هذا الأرشيف موجودة في جذر المشروع، بنفس أسماء الملفات الأصلية.
انسخ الملفات الأربعة إلى جذر مشروع antibiotic-awareness واستبدل النسخ القديمة فقط.

ما تم تغييره:
- OpenWorldGame.tsx / OpenWorldGame.css:
  * عصا تحكم ثابتة في الجهة اليسرى ماديًا حتى مع واجهة RTL.
  * وضع ملء الشاشة يخفي عناصر الواجهة غير الضرورية، مع زر قائمة عائم لفتح/إغلاق لوحة الأماكن.
  * مبانٍ قابلة للدخول بواجهات مفتوحة، مناطق داخلية وأثاث تعليمي، ولوحات أسماء للمباني والغرف بالعربية والإنجليزية.
  * منع حركة اللاعب عبر جدران المباني الرئيسية، مع إبقاء المداخل مفتوحة.
  * حفظ موضع الاستكشاف مع XP والأماكن التي تمت زيارتها محليًا وعلى Firestore لحساب المستخدم، وتحديث الموضع كل 5 ثوانٍ.
- GameCenter.tsx:
  * توضيح ميزات العالم المفتوح في بطاقة اللعبة بمركز الألعاب.
- MedicalSimulator.css:
  * توحيد وضع الجويستك يسارًا في المحاكاة المشتركة، وإخفاء لوحة السيناريوهات في وضع اللعب الغامر حتى يفتح المستخدم قائمة اللعبة.

مكان فتح العالم المفتوح:
مركز الألعاب > أول بطاقة باسم «عالم المدينة الصحية المفتوح / Open Health World»، أو المسار /open-world.

التحقق:
تم فحص صياغة TypeScript/JSX للملفات المعدلة وتوازن أقواس CSS. لم يتم تأكيد بناء Vite كامل لأن اعتماديات المشروع غير موجودة، والتثبيت دون اتصال لم ينجح. اختبر GitHub Actions قبل اعتبار التعديلات منشورة.

ملاحظة:
هذا تعديل عملي أولي لهيكل العالم المفتوح، وليس ادعاءً بأنه أصبح لعبة AAA أو مباني داخلية فوتوريالية بالكامل. لا يتضمن الأرشيف ملفات Firebase rules أو تغييرات في إعدادات النشر.
