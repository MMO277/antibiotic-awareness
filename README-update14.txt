Update 14 - Total Medicines Overhaul & Smart Firebase Override
============================================================

ما الذي يقدمه هذا التحديث الجذري؟
---------------------------------
1. حل مشكلة بقاء البيانات القديمة في Firebase:
   - تم تحديث medicinesApi.ts بنظام (Smart Merge) يدمج ويفرض الأسعار والبدائل والباركودات المصرية الحديثة تلقائياً ويتجاوز البيانات القديمة المسجلة في فايربيز.
2. اكتمال جميع الأدوية الـ 16 بدون استثناء في الموقع:
   - أموكسيسيلين (E-Mox / Biomox)
   - أموكسيسيلين + كلافولانات (Augmentin / Curam / Megamox / Hibiotic)
   - بنسلين V البوتاسيوم (Ospen 1000 / Ospen 1500)
   - أزيثرومايسين (Zithromax / Xithrone / Zithrokan)
   - ميترونيدازول (Flagyl / Amrizole)
   - نيتروفورانتوين (Macrofuran / Uvamin Retard)
   - سيبروفلوكساسين (Ciprofar / Cipromay)
   - كليندامايسين (Dalacin C / Clindam)
   - كلاريثرومايسين (Klacid / Clarikan)
   - دوكسيسيكلين (Tabocin / Vibramycin)
   - كوتريموكسازول (Septazole Forte / Sutrim Forte)
   - سيفوروكسيم (Zinnat / Cefurox)
   - سيفترياكسون (Epicephin / Cefaxone)
   - ليفوفلوكساسين (Tavanic / Levodel)
   - سيفالكسين (Ospexin / Cefalex / Ibilex)
   - سيفيكسيم (Suprax / Magnacef / Cefix)

3. كل دواء يحتوي على:
   - بطاقة QR Code وباركود في أعلى الصفحة ليراها مستخدمو الهواتف فوراً.
   - السعر الرسمي المحدث في السوق المصري (EGP).
   - قسم البدائل والمثائل الدوائية المتاحة في مصر مع أسعارها وبدائل الحساسية.
   - الباركود الدولي الفعلي المطبوع على علب الأدوية المصرية (EAN-13 يبدأ بـ 622) لمسحه بالكاميرا.

الملفات المضمنة في هذا التحديث (5 ملفات):
----------------------------------------
1. types.ts          -> الحقول والأنواع البرمجية الكاملة
2. medicinesApi.ts   -> محرك الدمج الذكي ومطابقة الباركود مع الكاميرا
3. seedData.ts       -> قاعدة البيانات الحصرية المكتملة لجميع الأدوية الـ 16
4. MedicinePage.tsx  -> رفع كود الـ QR لأعلى الصفحة وكروت الأسعار والبدائل
5. styles.css        -> التنسيقات البصرية لكروت الـ QR والأسعار
6. README-update14.txt -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات الخمسة إلى مستودع GitHub في نفس مسار App.tsx (استبدل الملفات القديمة).
2. اضغط Commit changes وانتظر دقيقة حتى تكتمل علامة الصح الخضراء في Actions.
3. افتح صفحة الأدوية أو أي دواء في الموقع (مثل أموكسيسيلين أو أوسبن أو أوجمنتين) وستجد كود الـ QR والسعر والبدائل والباركود ظاهرة ومكتملة فوراً!
