Update 18 - Antibiotic Treatment Tracker & Side Effects Emergency Guide
========================================================================

الميزتان التمريضيتان الجديدتان المضافتان للمشروع:
----------------------------------------------
1. ميزة «متابع كورس العلاج بالمضادات الحيوية» (/tracker):
   - أداة تنظيمية وجدول تفاعلي ذكي يساعد المريض على تسجيل وتتبع الجرعات الموصوفة له بدقة.
   - إدخال بيانات الروشتة (اسم الدواء، الجرعة، طريقة الاستعمال، عدد المرات، مواعيد الساعات، والمدة بالأيام).
   - جدول زمني يومي لكل جرعة (قادمة ⏳ / تم أخذها ✅ / غير مؤكدة ⚠️).
   - مؤشر بياني دقيق لنسبة الالتزام بالجدول (Adherence Progress Bar).
   - زر لتأكيد أخذ الجرعة أو التراجع عن التسجيل الخطأ.
   - تنبيهات واضحة للجرعات المنسية: توجيه بعدم مضاعفة الجرعة ومراجعة النشرة أو الصيدلي.
   - دعم التنبيهات المحلية لمتصفح الويب (Web Notifications) مع توضيح شفاف لقيودها في المتصفح.
   - حفظ كامل للبيانات محلياً على جهاز المريض (localStorage) دون جمع أي بيانات شخصية أو هوية.

2. ميزة «دليل الآثار الجانبية وخطة الطوارئ» (/side-effects):
   - صندوق أحمر بارز في أعلى وأول الصفحة لعلامات الطوارئ القاتلة (صعوبة التنفس، تورم اللسان والحلق، الصدمة التحسسية) مع رقم الإسعاف (123) يظهر فوراً دون ملء أي استبيان.
   - تقسيم الأعراض إلى 3 فئات طبية واضحة ومميزة لونياً:
     🟢 الفئة 1: أعراض شائعة وخفيفة (غثيان، ليونة براز مؤقتة، طعم معدني).
     🟡 الفئة 2: أعراض تستدعي استشارة عاجلة (إسهال مائي C. diff، ألم الأوتار، اليرقان).
     🔴 الفئة 3: علامات طوارئ خطيرة تتطلب الإسعاف فوراً.
   - مستكشف تفاعلي لأكثر من 10 أعراض سريرية يشرح الآلية البيولوجية، الإجراء الفوري، الأدوية المسببة، وتوجيهات التمريض.
   - ركن التوعية بالحساسية الدوائية والفرق بين الحساسية والأثر الجانبي العادي.
   - توثيق المراجع السريرية المعتمدة (CDC, MedlinePlus, NHS) وتاريخ المراجعة.

الملفات المضمنة في هذا التحديث (8 ملفات):
----------------------------------------
1. trackerData.ts        -> منطق حساب الجرعات، التوليد الزمني، وحفظ الجداول في localStorage
2. Tracker.tsx            -> صفحة متابع كورس العلاج والجدول الزمني والنسب المئوية
3. sideEffectsData.ts    -> قاعدة بيانات الأعراض الجانبية وتصنيف الطوارئ وتوجيهات التمريض
4. SideEffectsGuide.tsx  -> صفحة دليل الآثار الجانبية والمستكشف التفاعلي
5. App.tsx               -> ربط مسارات الصفحتين الجديدتين (/tracker و /side-effects)
6. Layout.tsx            -> إضافة الميزتين في قائمة الـ 3 شُرط الجانبية
7. i18n.tsx              -> التعريب الكامل والأسماء في القائمة
8. styles.css            -> التنسيقات البصرية الشاملة للجداول والكروت والمؤشرات
9. README-update18.txt   -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات إلى مستودع GitHub في نفس مسار App.tsx (استبدل الملفات القديمة وأضف الجديدة).
2. اضغط Commit changes وانتظر دقيقة حتى تكتمل علامة الصح الخضراء في Actions.
3. افتح موقعك وستجد في القائمة الجانبية:
   - ⏱️ متابع كورس العلاج
   - 🚨 دليل الآثار الجانبية والطوارئ
   وكلاهما جاهزان للعمل والاختبار والمناقشة فوراً!
