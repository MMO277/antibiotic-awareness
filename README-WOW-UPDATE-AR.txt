تحديث WOW — عالم المدينة الصحية + محاكاة المستشفى
====================================================

الملفات في هذا الأرشيف معدّلة فقط، وأسماؤها مطابقة لأسماء الملفات داخل جذر المشروع.

الملفات التي يجب استبدالها:
1. OpenWorldGame.tsx
2. OpenWorldGame.css
3. GameCenter.tsx
4. medicalSimulatorScene.ts
5. MedicalSimulator.tsx
6. MedicalSimulator.css
7. Cartoon3DGameShell.tsx

ما الذي تغيّر في هذه الدفعة؟
- توسيع عالم المدينة الصحية إلى سبعة مبانٍ تفاعلية: المستشفى، الصيدلية، مركز التعلّم، المركز المجتمعي، الأشعة، المعمل المركزي، والطوارئ.
- إضافة شوارع بعلامات أرضية ومعابر مشاة وأرصفة وإنارة ومقاعد وسيارة إسعاف وشخصيات تمشي في الساحة.
- تطوير شخصية اللاعب بملابس تمريض وتفاصيل تعريفية وحركة مشي أوضح.
- توسيع محيط المحاكاة الطبية المشتركة إلى جناح مستشفى أوسع مع ممر وأقسام للأشعة والمعمل ولوحات إرشادية ومعدات ظاهرة، بدل حصر الحركة في مساحة غرفة صغيرة.
- إضافة زر قائمة عائم في وضع اللعب الغامر داخل MedicalSimulator وCartoon3DGameShell؛ يمكن إظهار الشريط وإخفاؤه بدل بقائه فوق المشهد.
- تثبيت الجويستك في الجانب الأيسر الفعلي في واجهات المحاكاة المشتركة، بغض النظر عن اتجاه العربية/الإنجليزية.
- الإبقاء على بنية الحفظ السحابي الحالية؛ لم تُعدّل Firebase rules أو إعدادات النشر في هذه الدفعة.

طريقة الاستخدام:
1. خذ نسخة احتياطية من الملفات السبعة الموجودة عندك.
2. فك ضغط هذا الملف.
3. انسخ الملفات السبعة إلى جذر مشروع antibiotic-awareness واستبدل النسخ القديمة فقط.
4. ارفع التعديلات إلى فرع تجريبي أو اترك GitHub Actions يفحص البناء قبل دمجها في main.
5. افتح مركز الألعاب ثم «عالم المدينة الصحية المفتوح»، وجرّب الجويستك في محاكاة المستشفى المشتركة.

التحقق:
- تم تمرير ملفات TypeScript/TSX المعدّلة عبر TypeScript transpileModule للتحقق من سلامة الصياغة.
- تم تحليل ملفات CSS المعدّلة بواسطة PostCSS.
- لم يكتمل npm install في بيئة الفحص، لذلك لم يُتحقق من بناء Vite الكامل أو اختبار تشغيل WebGL في متصفح حقيقي. لا تعتبر التحديث منشورًا أو مضمون البناء قبل نجاح GitHub Actions والاختبار داخل الموقع.
- هذه ترقية كبيرة في البيئة والواجهة، لكنها ما زالت مبنية بأشكال Three.js إجرائية وليست أصولًا فوتوريالية جاهزة بمستوى لعبة تجارية ضخمة.
