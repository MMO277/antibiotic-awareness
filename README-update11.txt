Update 11 - Gemini AI Integration (المساعد الذكي فائق التوسع)
=============================================================

ما الذي يقدمه هذا التحديث؟
------------------------
1. ربط المساعد الذكي بنموذج Google Gemini 1.5 Flash (مجاني 100% عبر Google AI Studio).
2. الإجابة بمرونة ودقة وذكاء على أي سؤال يطرحه زوار الموقع، مع التزام صارم بضوابط مشروع التخرج التمريضي:
   - يمنع منعاً باتاً وصف جرعات شخصية أو تشخيص حالات.
   - يوضح الفرق بين البكتيريا والفيروسات، ويحذر من مجموعة البرد/حقنة هتلر.
   - يقدم إرشادات علمية دقيقة وفق مراجع منظمة الصحة العالمية (WHO) ومراكز السيطرة على الأمراض (CDC).
3. نظام هجين ذكي (Hybrid System):
   - إذا تم إدخال مفتاح Gemini: يجيب الذكاء الاصطناعي على أي سؤال مفتوح.
   - إذا لم يتم إدخال مفتاح أو انقطع الإنترنت: يعود تلقائياً لمحرك الموقع الداخلي بدون أي توقف أو أخطاء.
4. آمن 100% لمستودعات GitHub العامة: يتم حفظ المفتاح في متصفحك (localStorage) عبر زر الإعدادات الأنيق، فلا يتعرض للحظر من فاحص أمان GitHub.

الملفات في هذا التحديث (4 ملفات):
-------------------------------
1. geminiApi.ts         -> كود الاتصال بـ Gemini API وضبط التعليمات السريرية (System Prompt)
2. Assistant.tsx        -> صفحة المساعد المحدثة (تدعم الرد الذكي، مؤشر التحميل، وزر إدخال المفتاح)
3. styles.css           -> التنسيقات الكاملة للموقع مع تنسيقات شات الذكاء الاصطناعي الجديدة
4. README-update11.txt  -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات الثلاثة (geminiApi.ts, Assistant.tsx, styles.css) إلى مستودع GitHub في نفس مكان App.tsx (استبدل الملفات القديمة).
2. اعمل Commit وانتظر حتى تكتمل علامة الـ Build الخضراء على GitHub Pages.
3. افتح الموقع واذهب لصفحة المساعد الذكي (/assistant).
4. اضغط على زر "⚙️ ربط Gemini AI مجاناً" بالأعلى.
5. ادخل المفتاح المجاني الذي استخرجته من Google AI Studio واضغط "حفظ".
   (سيعمل المساعد فوراً بالذكاء الاصطناعي!).

كيفية استخراج مفتاح Google Gemini مجاناً في دقيقة واحدة:
------------------------------------------------------
1. ادخل على الموقع: https://aistudio.google.com/
2. سجل دخول بحسابك في Google.
3. اضغط على الزر الأزرق: "Get API key" (أو Create API key).
4. انسخ المفتاح والصقه في واجهة المساعد بالموقع.
