تعديلات تجربة المحاكاة ثلاثية الأبعاد

استبدل الملفات الستة الموجودة في جذر المشروع بالملفات الموجودة هنا، مع الحفاظ على نفس أسماء الملفات:
- MedicalSimulator.tsx
- Cartoon3DGameShell.tsx
- MedicalSimulator.css
- Cartoon3DGameShell.css
- medicalSimulatorScene.ts
- cartoon3DSceneBuilder.ts

ما تم تعديله:
- الجويستك ثابت على الجهة اليسرى فعلياً حتى مع واجهة اللغة العربية.
- أثناء وضع اللعب الغامر تختفي القوائم الدائمة وشريط الأهداف والمعلومات الجانبية، ويظهر سهم عائم لفتح/إخفاء قائمة اللعبة عند الحاجة.
- توسيع مساحة عالم المحاكاة وإضافة ممر مستشفى ولافتات إرشادية للأشعة والإجراءات وجناح المرضى والمختبر المركزي في مشهدي المحاكاة المشتركين.
- لم يتم تعديل منطق Firebase أو الحفظ السحابي.

التحقق:
- نجح فحص التحليل النحوي لملفات TypeScript/TSX الأربعة.
- لم يمكن تشغيل typecheck/build الكامل لأن اعتماديات المشروع غير مثبتة في بيئة الفحص (مثل vite/client). يجب التأكد من نجاح GitHub Actions قبل اعتبار التحديث جاهزاً للنشر.

مهم: هذه دفعة أولى للواجهة والممر والإرشادات؛ تحويل كل قسم إلى غرف مستقلة كاملة التفاعل يحتاج دفعة هندسية إضافية بعد تجربة هذا التغيير.
