Update 20 - Smart Allergy & Medication Safety System + My Health Profile
========================================================================

موقف Firebase:
-------------
لا يوجد أي تعديل نهائياً على Firebase (قواعد الأمان والبيانات لا تُلمس تماماً، والميزة تعمل بالكامل ومحلياً على جهاز المريض بأعلى معايير الخصوصية والأمان).

ما الذي يقدمه هذا التحديث الشامل لمشروع التخرج؟
---------------------------------------------
1. ميزة «ملف صحتي وحساسيتي الدوائية» (/health-profile):
   - تسجيل بيانات المريض (الاسم، العمر، فصيلة الدم، هاتف الطوارئ).
   - سجل الحساسية الدوائية (My Allergies): توثيق الأدوية التي تسبب حساسية، العائلة الدوائية (بنسلين، سيفالوسبورين، سلفا...)، الأعراض، درجة الخطورة، وحالة التوثيق السريري.
   - سجل الأدوية الحالية والسابقة (My Medications).
   - ملخص بياني وإحصائي للسلامة الدوائية وتصدير الملف (Export JSON) لطباعته أو حفظه.

2. ميزة «فاحص الحساسية والأمان الدوائي الذكي» (/allergy-checker):
   - يفحص المادة الفعالة لأي مضاد حيوي ويقارنها مع سجل حساسية المريض بدقة سريرية.
   - يتعامل مع الأدوية المركبة (مثل أوجمنتين = أموكسيسيلين + كلافولانات).
   - مستويات التحذير السريرية المعتمدة:
     🔴 خطر حاد (Exact Match): تطابق تام في المادة الفعالة أو العائلة مع تنبيه صدمة تحسسية.
     🟠 تحذير سريري (Cross-Reactivity): كشف احتمالية الحساسية المتصالبة بين البنسلين والسيفالوسبورينات.
     🟢 آمن (No Match): لا يوجد تطابق مع الحساسيات المسجلة.
   - دعم «السيناريوهات السريرية السريعة» لتجربة فحص مريض لديه حساسية بنسلين أو سلفا أمام لجنة التحكيم بضغطة زر واحدة!

الملفات المضمنة في هذا التحديث (8 ملفات):
----------------------------------------
1. allergyData.ts      -> قاعدة بيانات المواد الفعالة والحساسية المتصالبة وإدارة التخزين
2. HealthProfile.tsx    -> صفحة ملف صحتي وسجل الحساسية ولوحة التحكم
3. AllergyChecker.tsx  -> صفحة فاحص الحساسية التفاعلي ومحاكي السيناريوهات
4. App.tsx             -> إضافة مسارات الصفحات الجديدة (/health-profile و /allergy-checker)
5. Layout.tsx          -> إضافة الروابط في قائمة الـ 3 شُرط (👤 و 🛡️)
6. i18n.tsx            -> مفاتيح التعريب والترجمة
7. ChatWidget.tsx      -> بابل المساعد الذكي
8. styles.css          -> التنسيقات البصرية الشاملة لكروت الحساسية ولوحة الملف
9. README-update20.txt -> هذا الملف الإرشادي

طريقة التثبيت:
------------
1. ارفع الملفات إلى مستودع GitHub في نفس مسار App.tsx (استبدل الملفات القديمة وأضف الجديدة).
2. اضغط Commit changes وانتظر دقيقة حتى تكتمل علامة الصح الخضراء في Actions.
3. افتح موقعك وستجد في القائمة الجانبية (☰):
   - 👤 ملف صحتي وحساسيتي
   - 🛡️ فاحص الحساسية الذكي
   وكلاهما جاهزان للعمل المباشر ومبهران جداً في المناقشة!
